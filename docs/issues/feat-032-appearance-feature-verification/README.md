# feat-032: ポーズ誘導外観特徴量の独立検証

## ステータス

Open（調査・設計フェーズ）

## 概要

`scripts/custom_reid.py` 内に埋め込まれている「ポーズ誘導外観特徴量」計算ロジック（キーポイントで頭部・胴体ROIを切り出し、HSV色ヒストグラムを計算し、EMAで時間平滑化する処理）を独立モジュールとして切り出し、Re-IDマッチングと分離して単独で動作・観測できる環境を構築する。

## 背景

feat-026「見切れ再同定の検証」において、画面中央の対象（stable_id=1）の前を別の人物が横切ると、stable_id=1の追跡が42分間途切れる問題が確認された（フレーム6856→82583）。原因調査の結果、Deep OC-SORTのIDスイッチ発生時（フレーム6377付近）にポーズ誘導外観特徴量のEMA更新が無条件で実行され、別人の外見でEMAが汚染されることが判明した。

当初はEMA更新前の類似度チェック追加という方針で進めていたが、Re-ID（stable_id管理） / Deep OC-SORT（トラッカー） / ポーズ誘導外観特徴量計算の3要素が `custom_reid.py` 内で密結合しているため、修正方針を詰めるには汚染の実態を独立に観測できる環境が必要と判断した。

## 目的

- `custom_reid.py` からポーズ誘導外観特徴量計算ロジックを独立モジュールとして切り出す
- Re-IDマッチングに依存しない検証スクリプトで、実動画における特徴量の時系列変化を可視化・定量化する
- IDスイッチ発生箇所（例: frame 6377付近）で特徴量がどのタイミング・速度で汚染されるかを観察する
- EMA更新の汚染を防ぐための判定基準候補（EMA類似度、時間連続性、BB幾何変化など）を実データで評価する

## スコープ外

- Re-ID（stable_id割り当て、_disappeared照合、遅延マッチ）ロジックの変更 → feat-026凍結中
- Deep OC-SORTの設定変更・別トラッカーへの置き換え → 現状維持
- パイプライン本体（`run_halpe26_pipeline_yolo11.py`）の変更

## 前提

- feat-026は凍結中。Re-ID修正方針はfeat-032の結果を受けて再検討する
- Deep OC-SORTは現状維持（BoxMOTのデフォルト設定）
- 入力は既存出力 `experiments/results/camSony1_L_reid_json/` と動画 `experiments/input/camSony1_L.mp4` を利用
