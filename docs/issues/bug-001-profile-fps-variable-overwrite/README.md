# bug-001: プロファイル表示で変数fpsが動画FPSを上書きする

## 概要

`run_halpe26_pipeline.py` 191行目で、プロファイル用の処理FPSを `fps` 変数に代入しているが、70行目で取得した動画のFPS（`cap.get(cv2.CAP_PROP_FPS)`）と同名であり上書きされる。現時点では上書き後に元の動画FPSを参照する箇所がないため実害はないが、将来のコード追加時にバグの原因となる。

## 再現手順

1. `--profile` 付きで実行
2. 191行目で `fps` が上書きされる
3. 以降のコードで動画のFPSを参照すると誤った値が使われる（現時点では該当箇所なし）
