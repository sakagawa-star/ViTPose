# feat-022: BoxMOT + Deep OC-SORT 室内動画検証レポート

## 1. 検証目的

BoxMOT + Deep OC-SORTが室内動画のトラッキング要件を満たすか検証する。

### 要件

- 室内動画（1時間単位）で同一人物にIDを維持する
- 人が完全に映っていない時間（5〜10秒）の後、再び映った時に同一IDで追跡を再開する
- 人物トラッキング自体が重要な目的である（対象特定はその一部）

## 2. 検証環境

| 項目 | 値 |
|------|-----|
| BoxMOT | 16.0.11 |
| トラッカー | DeepOcSort |
| Re-IDモデル | OSNet (osnet_x0_25_msmt17, 2.2Mパラメータ) |
| GPU | NVIDIA GeForce RTX 5060 Ti |
| テストスクリプト | `scripts/test_boxmot_offline.py`（feat-021で作成） |

## 3. テストデータ

| 項目 | 値 |
|------|-----|
| 動画 | `testdata/camSony1_S.mp4`（960x540, 30fps, 900フレーム, 30秒） |
| JSON | `experiments/results/camSony1_S_json/`（900ファイル, bbox + bbox_score付き） |
| 映っている人物 | 1人（同一の対象） |
| 動画の特徴 | 室内の固定カメラ映像。布団による遮蔽あり。人が映らない区間が複数存在 |

### 検出途切れ区間

JSONの分析により、以下の区間で人物検出が0人となっている:

| 区間 | フレーム | 時間 | 原因 |
|------|---------|------|------|
| 28〜105 | 78フレーム | 2.6秒 | 布団遮蔽で検出不能 |
| 約180付近 | 数フレーム | 短時間 | 一時的な検出失敗 |
| 596〜688 | 93フレーム | 3.1秒 | 布団遮蔽で検出不能 |

## 4. 検証1: デフォルトパラメータでの実行

### 実行コマンド

```bash
uv run python scripts/test_boxmot_offline.py \
  --video testdata/camSony1_S.mp4 \
  --json-dir experiments/results/camSony1_S_json/
```

### 結果

```
Total frames: 900
Skipped frames: 0
Unique track IDs: {1: 25, 2: 475, 7: 198, 10: 6}
  ID 1: 25 frames
  ID 2: 475 frames
  ID 7: 198 frames
  ID 10: 6 frames
Processing time: 8.0 sec (112.0 fps)
```

### 分析

| ID | フレーム数 | 推定区間 | 説明 |
|----|----------|---------|------|
| 1 | 25 | 0〜27 | 最初の検出期間。検出途切れ（78フレーム）後にIDが変わる |
| 2 | 475 | 106〜595 | 最長の検出期間。検出されている間はIDが安定 |
| 7 | 198 | 689〜899 | 2回目の検出途切れ（93フレーム）後に新しいIDが付与 |
| 10 | 6 | 880付近 | 短時間の誤検出 |

**問題**: 検出が途切れるたびにIDが変わる（1→2→7）。Re-IDによる再同定が機能していない。

## 5. 検証2: max_ageパラメータの調整

### 仮説

`max_age`（追跡を保持するフレーム数）がデフォルト30のため、検出途切れ78フレームで追跡が打ち切られている。`max_age`を大きくすれば改善する可能性がある。

### 実行

| max_age | 理論上の保持時間（@30fps） |
|---------|------------------------|
| 30（デフォルト） | 1.0秒 |
| 90 | 3.0秒 |
| 150 | 5.0秒 |
| 300 | 10.0秒 |

### 結果

```
max_age=30:  {1: 25, 2: 475, 7: 198, 10: 6}  Unique IDs: 4
max_age=90:  {1: 25, 2: 475, 7: 198, 10: 6}  Unique IDs: 4
max_age=150: {1: 25, 2: 475, 7: 198, 10: 6}  Unique IDs: 4
max_age=300: {1: 25, 2: 475, 7: 198, 10: 6}  Unique IDs: 4
```

**全て同一の結果**。max_ageを10倍にしても改善なし。

### 分析

max_age=300では10秒間追跡を保持するはずだが、検出途切れ2.6秒（78フレーム）でもIDが変わる。追跡保持の問題ではなく、**再出現時のRe-IDマッチングが失敗**している。

## 6. 検証3: Re-ID関連パラメータの調整

### 仮説

Re-IDのembedding重みやマッチング閾値を変更すれば、再同定の精度が改善する可能性がある。

### 実行パラメータ

| 設定 | w_association_emb | alpha_fixed_emb | その他 |
|------|:-:|:-:|------|
| デフォルト | 0.5 | 0.95 | — |
| Re-ID重み増加 | 0.75 | 0.95 | — |
| Re-ID重み最大＋特徴量更新緩和 | 0.9 | 0.5 | — |
| min_hits低下 | 0.5 | 0.95 | min_hits=1 |

### 結果

```
w_association_emb=0.5, alpha_fixed_emb=0.95:  {1: 25, 2: 475, 7: 198, 10: 6}   Unique IDs: 4
w_association_emb=0.75, alpha_fixed_emb=0.95: {1: 25, 2: 475, 7: 198, 10: 6}   Unique IDs: 4
w_association_emb=0.9, alpha_fixed_emb=0.5:   {1: 25, 2: 475, 7: 192, 10: 11}  Unique IDs: 4
min_hits=1:                                   {1: 28, 2: 485, ..., 7: 205, ...} Unique IDs: 7（悪化）
```

**改善なし**。Re-ID重みを最大にしても、min_hitsを下げても（むしろ悪化）、IDの一貫性は改善されない。

## 7. 検証4: det_threshの調整

### 実行

```
det_thresh=0.3 (デフォルト): {1: 25, 2: 475, 7: 198, 10: 6}  Unique IDs: 4
det_thresh=0.1:              {1: 25, 2: 475, 7: 198, 10: 6}  Unique IDs: 4
```

**改善なし**。

## 8. 結論

### 根本原因

**Re-IDモデル（OSNet, osnet_x0_25_msmt17）が室内環境で同一人物を再同定できない。**

- OSNetはMSMT17（街中の歩行者データセット）で訓練されており、室内の対象（臥位、病院着、低解像度）とはドメインが大きく異なる
- 検出されている間はトラッキング（IoU + Kalmanフィルタ）で安定してIDが維持されるが、検出が途切れると再同定にRe-IDが必要になり、そこで失敗する
- `max_age`、`w_association_emb`、`alpha_fixed_emb`、`det_thresh`、`min_hits`のいずれのパラメータを調整しても改善しない

### 要件との対比

| 要件 | 結果 | 判定 |
|------|------|:--:|
| 検出されている間のID維持 | ID 2が475フレーム連続で安定 | OK |
| 5〜10秒の見切れ後のID再同定 | 2.6秒の途切れでもID変更（1→2） | **NG** |
| 処理速度 | 112 fps（十分高速） | OK |

### BoxMOT + Deep OC-SORTの評価

- **検出中のトラッキング**: 良好。IoU + Kalmanフィルタで安定したID維持
- **見切れ後の再同定**: 不可。Re-IDモデルのドメイン不適合が原因
- **パラメータ調整による改善**: 不可能。根本原因がモデルのドメイン不適合のため

### 今後の検討事項

1. **BoxMOT内の他のRe-IDモデルを試す** — CLIPReIDなど、より汎用的な視覚特徴を使うモデルで再同定力が改善するか確認
2. **BoxMOT内の他のトラッカーを試す** — StrongSORT、BoTSORT等
3. **根本的にアプローチを変える** — bboxトラッキング以外の手法（ポーズベース等）を調査
