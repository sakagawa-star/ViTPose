# 要求仕様書: feat-011 結合結果の可視化・検証

## 1. プロジェクト概要

- **何を作るか**: HALPE 26結合ロジック（feat-009）を動画に適用し、全フレームでキーポイントが正しく描画された可視化動画を作成する。静止画（feat-009の確認）と動画の両方で結合結果の正しさを目視検証する
- **なぜ作るか**: feat-009では全身が映るテスト画像が得られず、マッピングの正しさを十分に確認できなかった。全身が映る動画でHALPE 26の全キーポイント（Head, Neck, Hip center, 足6点を含む）の位置・左右の正しさを検証する
- **誰が使うか**: 開発者（自分自身）
- **どこで使うか**: ローカルGPU環境（RTX 5060 Ti, CUDA 12.8）

## 2. 用語定義

| 用語 | 定義 |
|------|------|
| HALPE 26 | 26キーポイント定義。COCO 17 + Head + Neck + Hip center + 足6点 |
| Pexelsテスト動画 | `output/feat-009/pexels_4441000.mp4`（1920x1080, 25fps, 1244フレーム, 49.8秒）。全身が映る男性の動画 |
| 室内テスト動画 | `/home/sakagawa/git/ViTPose_HuggingFace/input/cam05520129.mp4`（1920x1080, 30fps, 902フレーム, 30.1秒）。本プロジェクトの実際のターゲット動画 |

## 3. 機能要求一覧

### FR-001: HALPE 26動画可視化スクリプトの作成

- **機能名**: HALPE 26キーポイントの動画可視化スクリプト
- **概要**: 入力動画の各フレームに対してWholeBody推定とAIC推定を行い、HALPE 26に結合し、キーポイント＋スケルトンを描画した可視化動画を出力する
- **入力**:
  - 動画ファイル（コマンドライン引数で指定）
  - 人物検出モデル: Faster R-CNN（R-50-FPN）
  - WholeBodyモデル: `checkpoints/wholebody.pth`
  - AICモデル: `checkpoints/aic.pth`
- **出力**: 可視化動画（入力と同じ解像度・fps）
- **受け入れ基準**:
  - スクリプト `scripts/visualize_halpe26_video.py` が存在する
  - スクリプトがエラーなく実行完了する
  - 出力動画の解像度・fpsが入力動画と同一であること
  - 出力動画のフレーム数が入力動画と同一であること

### FR-002: Pexelsテスト動画での可視化・検証

- **機能名**: 全身が映る動画でのHALPE 26検証
- **概要**: Pexelsテスト動画に対してFR-001のスクリプトを実行し、HALPE 26の全キーポイントの正しさを目視検証する
- **入力**: `output/feat-009/pexels_4441000.mp4`
- **出力**: `output/feat-011/vis_halpe26_pexels_4441000.mp4`
- **受け入れ基準**:
  - 出力動画が存在し再生可能である
  - 出力動画の解像度が入力と同一（1920x1080）である
  - 目視で以下を確認:
    - HALPE 0-16（COCO 17相当）が正しい位置にある
    - HALPE 17（Head）が頭頂付近にある
    - HALPE 18（Neck）が首の付け根付近にある
    - HALPE 19（Hip center）が左右Hipの中間にある
    - HALPE 20-25（足6点）の左右が正しい

### FR-003: 室内テスト動画での可視化・検証

- **機能名**: 室内動画でのHALPE 26検証
- **概要**: 本プロジェクトのターゲット動画に対してFR-001のスクリプトを実行し、遮蔽環境でもHALPE 26が安定して出力されることを確認する
- **入力**: `/home/sakagawa/git/ViTPose_HuggingFace/input/cam05520129.mp4`
- **出力**: `output/feat-011/vis_halpe26_cam05520129.mp4`
- **受け入れ基準**:
  - 出力動画が存在し再生可能である
  - 出力動画の解像度が入力と同一（1920x1080）である
  - デモスクリプトがエラーなく完了する
  - 目視で少なくとも1人分のHALPE 26キーポイントとスケルトンが描画されていること

## 4. 非機能要求

- **処理時間**: 各動画の処理が30分以内に完了する
- **GPU使用**: CUDA対応GPUで推論する
- **信頼性**: 出力ファイルは再実行により再生成可能

## 5. 制約条件

- feat-009で作成した `merge_to_halpe26()` と `draw_halpe26()` 関数を再利用する（`scripts/merge_halpe26.py` からインポート）
- MMPoseの推論APIを使用する
- 人物検出は各フレームで1回のみ行い、WholeBodyとAICで共有する
