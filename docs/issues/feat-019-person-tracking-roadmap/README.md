# feat-019: 人物トラッキング実装のための調査とロードマップ

## ステータス: Closed (2026-03-29)

## 概要

HALPE 26パイプラインに人物トラッキング機能を追加するための調査とロードマップを作成する。

## 背景

- 病室動画で通常1人の患者を撮影しているが、看護師等が来ると2人以上になる
- 患者のキーポイントのみを後処理で抽出するため、フレーム間で同一人物にIDを維持する必要がある
- 患者の特定は「最も長時間映っているID＝患者」というルールで行う（後処理）
- トラッキングIDが変わった場合（画面外での着替え等）は人間が紐付ける

## 成果物

- `investigation.md`: トラッキング手法の調査レポート＋段階的実装ロードマップ
