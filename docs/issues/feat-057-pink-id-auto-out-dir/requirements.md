# feat-057 要求仕様書: postprocess_pink_id.py の --out-dir 自動導出（任意化）

## 1.1 プロジェクト概要

- **何を作るのか**: `scripts/postprocess_pink_id.py` の CLI 引数 `--out-dir` を必須（`required=True`）から任意に変更し、未指定時は `--json-dir` の値から固定規則で出力先を自動導出する。
- **なぜ作るのか**: 現状 `--out-dir` は毎回手入力が必要で煩雑。入力ディレクトリ名に固定接尾辞を付けた命名で自動生成できれば省略でき、操作負荷を下げられる。
- **誰が使うのか**: 本リポジトリで pink_id ポストプロセスを実行する開発者（ユーザー本人）。
- **どこで使うのか**: ローカル CLI 実行（`uv run python scripts/postprocess_pink_id.py ...`）。

## 1.2 用語定義

- **json-dir**: `--json-dir` で指定する入力 HALPE 26 JSON ディレクトリ。
- **out-dir**: `--out-dir` で指定する出力 JSON ディレクトリ。
- **自動導出**: `--out-dir` 未指定時に `--json-dir` の値から規則的に出力先パスを決定すること。
- **導出接尾辞**: 自動導出時に json-dir 末尾へ付与する固定文字列。本案件では `_pink_id` とする。

## 1.3 機能要求一覧

### FR-001: --out-dir の任意化

- **機能名**: `--out-dir` を任意引数に変更
- **概要**: `--out-dir` の `required=True` を外す。明示指定された場合は従来どおりその値を出力先として使用する。
- **入力**: CLI 引数 `--out-dir <path>`（省略可能）
- **出力**: 指定値が出力 JSON ディレクトリとして使用される（従来と同一動作）
- **受け入れ基準**:
  - AC-001-1: `--out-dir` を明示指定した実行結果が、改修前と完全一致する（同一入力で出力 JSON が `diff -r` で差分0）。
  - AC-001-2: `--out-dir` を省略してもエラーにならず実行が完了する。

### FR-002: --out-dir 未指定時の自動導出

- **機能名**: `--json-dir` からの出力先自動導出
- **概要**: `--out-dir` 未指定時、`os.path.normpath(json_dir) + "_pink_id"` を出力先とする。
- **入力**: `--json-dir <path>`（`--out-dir` は未指定）
- **出力**: 導出されたパスが出力先ディレクトリとして作成・使用される
- **受け入れ基準**:
  - AC-002-1: `--json-dir output/cam_json` で `--out-dir` 省略時、出力先が `output/cam_json_pink_id` になる。
  - AC-002-2: 末尾スラッシュ付き `--json-dir output/cam_json/` でも出力先が `output/cam_json_pink_id` になる（normpath により末尾スラッシュは無視される）。
  - AC-002-3: 自動導出された出力先で実行した結果の JSON 内容が、同じ出力先を `--out-dir` で明示指定した場合と一致する。
  - AC-002-4: 自動導出が発生したとき、導出先パスを示す標準出力が1行表示される（例: `[INFO] --out-dir not specified, using derived path: <path>`）。

### FR-003: 上書き防止チェックの維持

- **機能名**: json-dir と out-dir の同一禁止チェック維持
- **概要**: 既存の「`--json-dir` と `--out-dir` が同一実体パスのとき exit 1」チェックを維持する。自動導出時は接尾辞付与により必ず別パスになるため通常は抵触しない。
- **入力**: `--json-dir` と `--out-dir` に同一実体パスを明示指定
- **出力**: エラーメッセージを表示して exit 1（従来と同一）
- **受け入れ基準**:
  - AC-003-1: `--json-dir` と `--out-dir` に同一パスを明示指定すると、従来どおり exit 1 で終了する。

## 1.4 非機能要求

- **パフォーマンス**: 本改修は引数解決のみで、推論・描画処理には影響しない。処理時間は改修前と同等（測定誤差範囲）。
- **対応環境**: 既存の `postprocess_pink_id.py` 実行環境（Python 3.10.16 / uv）。新規ライブラリ追加なし。
- **信頼性**: 自動導出パスが既存ディレクトリの場合、従来同様 `os.makedirs(..., exist_ok=True)` で再利用し、同名ファイルは上書きする（現行挙動を踏襲）。

## 1.5 制約条件

- 新規ライブラリ追加禁止（標準ライブラリ `os` のみ使用）。
- `--out-dir` 以外の CLI 引数・出力 JSON スキーマ・選択ロジックは変更しない。
- `merge_halpe26.py` / `visualize_patient_video.py` など他スクリプトは無変更。
