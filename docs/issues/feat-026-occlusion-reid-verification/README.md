# feat-026: 見切れ再同定の検証

## ステータス: Open (feat-028待ち)

## 概要

camSony1_L（長尺動画、321,239フレーム、約3時間）でカスタムRe-ID（遅延マッチN=180）の見切れ再同定精度を検証する。

検証観点:
1. 見切れ後に戻ってきた同一人物に同じstable_idを割り当てるか（再同定の正確性）
2. 異なる人物に同じstable_idを割り当てないか（誤同定の防止）

feat-022ではcamSony1_S（900フレーム、見切れ区間のクリップ）で92.8%の収束率を確認済み。本案件では全体を通した検証を行う。

## 依存

- feat-022（カスタムRe-IDモジュール）— 完了済み
- feat-025（BB重複除去方式）— 完了済み
- **feat-028（JSONにトラッキングID記録）— 未完了、本案件のブロッカー**

## ブロック理由

feat-026の初回実装では、Re-ID結果（stable_id）を標準出力の統計サマリーとしてのみ出力していた。しかし、検証にはstable_idごとのスケルトン可視化が必要であり、そのためにはper-frameのstable_id → キーポイント対応がJSONに保存されている必要がある。

feat-028でJSONにstable_idを記録する機能を先に実装し、その出力を使って本案件の検証を行う。
