# feat-060: 静止画1枚のポーズ推定診断ツール

## 概要

1枚の静止画に対し、以下2経路を実行して結果を並べて出力する診断 CLI ツール
`scripts/diagnose_pose.py` を新規作成する。

1. **YOLO検出経路**: YOLO11x で person を検出し、検出数・各 BB の confidence を出力
2. **全画像1BB経路**: 画像全体を1つの BB として ViTPose（WB+AIC）に流し、
   HALPE26 キーポイントと各点 confidence を出力

両経路の可視化を1枚の PNG に合成して保存する。

## 動機

モノクロ・遮蔽の多い静止画で、ViTPose パイプライン（YOLO検出→トップダウン推定）が
キーポイントを出力しないケースが報告された。原因が

- ① YOLO の person 検出失敗（BB が出ない → トップダウン推定が走らない）
- ② ViTPose 自体が当該画像でポーズ推定に失敗

のどちらかを切り分けるツールがない。本ツールは「YOLO検出の成否」と「検出に依存しない
全画像1BB推論の成否」を同時に観測し、原因を一意に特定できるようにする。
